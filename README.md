## 🚀 Design System: Dole Sport Elite
This project uses a custom design system called **Dole Sport Elite**. 
Before making any UI changes, please read the [**AGENTS.md**](./AGENTS.md) file for critical rules on:
- **Sharpness:** 0px border-radius, no shadows.
- **Colors:** High-contrast (Black/White/Neon Orange).
- **Typography:** Geist Variable (Bold/Italic).
